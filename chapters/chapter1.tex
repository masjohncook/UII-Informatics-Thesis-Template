\section{Equations and Nomenclature}

Nomenclature is also often called Symbols section. We add the Plank constant 
symbol to the nomenclature. See the HOW TO text file to know the steps to compile
the nomenclature if you need it. 

\begin{equation}
F(x)= \int^a_b \frac{\gamma}{3}h^3 \label{eq}
\end{equation}
% first use of the symbol for Planck constant force so we declare for nomenclature -- does not appear in the text
\nomenclature{$a$}{first parameter}
\nomenclature{$b$}{second parameter}
\nomenclature{$h$}{Planck constant}
\nomenclature{$\gamma$}{Magical parameter found randomly}

There is a file in the folder Infos called "acronyms.tex"
\begin{lstlisting}[basicstyle=\small, label=some-code,caption=Content of acronyms.tex]
\begin{acronym}

\acro{TW}{Taiwan}
%\acro{acronym in text}{full corresponding text}
\end{acronym}
\end{lstlisting}
"acronyms.text" is inserted in the "main.tex" under the chapter acronyms. There is a "*" next to chapter
to indicate the compiler not to number this chapter but still include it in the Table of Content.
\par 
blablablablabl \ac{NCTU} , first time I am talking about NCTU. 
Bloblobbloblob \ac{NCTU}, I already talked about NCTU. 
Bliblibliblibli \acl{NCTU} if I want to reuse the full name after.

\begin{lstlisting}[basicstyle=\small, label=some-code,caption=Acronyms]
blablablablabl \ac{NCTU} , first time I am talking about NCTU. 
Bloblobbloblob \ac{NCTU}, I already talked about NCTU.

\end{lstlisting}

If you try something that was not put in the file "Infos/acronyms.tex" like "BYOB", 
when you use the acronym command it will appear like this: \ac{BYOB}. \\
Please not that just writing in Capital letter will have the same effect as using the short acronym command, it is up to you to use it. You still need to write it in acronyms.tex, the compiler cannot
read in your brain (yet..).
